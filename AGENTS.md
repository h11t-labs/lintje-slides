# Projectregels — @lintje/slides

Dit is de repo van het pakket `@lintje/slides`: presentaties in HTML met Lintje. De regels voor
werken aan het pakket staan in [`CONTRIBUTING.md`](CONTRIBUTING.md).

- **Een presentatie maken of controleren** volgt de skill
  [`skills/lintje-slides/SKILL.md`](skills/lintje-slides/SKILL.md); `npx lintje-slides` werkt
  hier ook. Een eigen deck om te proberen staat in `decks/`, dat niet in git komt.
- **De skill is wat een gebruiker van het pakket leest.** Een wijziging aan een indeling, een veld,
  de controle of de opdracht komt in dezelfde commit in de skill; de catalogus
  (`skills/lintje-slides/layouts.md`) schrijft `npm run catalog` uit `src/layouts.js`.
